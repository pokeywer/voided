/obfuscate — How it works

Users run /obfuscate file:<upload> or /obfuscate code:<paste> in Discord. The bot stores the script for 10 minutes and replies with a one-time link.

Flow:
  1. User uploads a .lua file or pastes code in Discord with /obfuscate
  2. Bot saves it to Firestore with a 10-minute expiry, replies with a secure link
  3. Link opens the VoidedX Creator Panel with the script pre-loaded and the chosen strength pre-set
  4. User clicks Preview & Download — the full VoidedX obfuscation engine runs in their browser
  5. Download the obfuscated .lua file directly
Obfuscation levels available via Discord: Auto · Fast · Low · Medium · High · Absolute
