How the key system works (quick guide)
  1. Turn it on. Enable the key system, then choose who gets keys: a Public Key for visitors, Private Keys for people you pick, or both.
  2. Share one link. Open Share link and send the Get-Key link to players. Public keys are issued from that page — never share private keys there.
  3. Optional link step. If you set a custom HTTPS link, visitors must finish it and return through your reward URL. Copy the ticket template from Share link and keep the {vx_ticket} placeholder.
  4. Save. Click Apply Changes. Settings and keys update immediately; players already running are not interrupted.
