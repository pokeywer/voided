How today’s activity is counted

“Active users” counts distinct Roblox UserIds reported by loader requests today. IDs are supplied by the client and are not independently verified, so this is a usage estimate—not proof of unique people. Load counts mean code was delivered after loader checks; they cannot confirm that code finished running in Roblox. Tracking starts after deployment, and older keyless loadstrings may need to be copied again to report a player ID.
