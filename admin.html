Changes this vault’s lifetime count and overall total. Daily and monthly leaderboard history stays unchanged.

Fast: Uses one VM layer, a light armor pass, and skips source string splitting to reduce execution work. It should run faster than Low, but is easier to analyze than the stronger presets.

VoidedX armor: Every copy is compiled to VM bytecode, then repacked in the VoidedX container with renamed internals, shuffled and masked segments, a compressed payload, and integrity checks. Every strength uses a single VM layer; High and Absolute add the Strong preset and heavier armor. A failed compile stops saving, leaving the live vault unchanged.

Absolute: Uses the Strong preset, the heaviest armor pass, tamper checking, and extra string splitting. It is the slowest option and may break scripts or exceed storage limits.
